## Accurate shared description

ReachSocial provides one API for normalized public social profiles, posts, and feeds.
Eight public REST services for Instagram, X, and TikTok accept $0.05 native Base-USDC
payments via x402 v2. Authenticated MCP is available to approved clients, with
service permissions. OAuth MCP payment approval is under owner-only validation
until all 15 services have acceptance and observation evidence. Do not advertise
anonymous USDC-paid MCP, unrestricted catalog availability, general OAuth login,
or a published open-source backend.

Website: https://reachsocial.dev
Docs: https://reachsocial.dev/docs/api
REST discovery: https://reachsocial.dev/v1/services
OpenAPI: https://reachsocial.dev/openapi.json
MCP endpoint: https://reachsocial.dev/mcp/
Logo: https://reachsocial.dev/static/reachsocial-logo.svg
Access requests: https://reachsocial.dev/contact

## Submission safety and follow-up

- Request directory account credentials only through hidden local input; never chat.
- Directory keys are not runtime application keys. Do not use provider, CDP,
  merchant-wallet, or admin credentials to authenticate directory submissions.
- An account API key does not replace owner wallet approval for SIWX.
- Never share production customer keys for directory health checks. Provision a
  dedicated review client only after its tool permissions and zero-spend limits
  are defined; do not weaken MCP authentication to make a crawler pass.
- Before another submission, check existing records for duplicates and compare the
  live catalog and payment metadata.
- Track confirmation emails, review changes, and final listing URLs here.
- Preserve input validation and required idempotency. A crawler compatibility issue
  does not justify settling invalid input or removing replay protections.
