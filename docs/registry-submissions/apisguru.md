ReachSocial returns normalized public social profiles, posts, and feeds. Public REST services accept x402 v2 payments in native USDC on Base mainnet ($0.05 per request). Current executable services: https://reachsocial.dev/v1/services. Documentation: https://reachsocial.dev/docs/api.

Anonymous paid requests require a random 32–255-character Idempotency-Key; recovery uses the same key and original input without another payment. Private API-key and MCP integrations require approved access and are separate from the public paid REST offering.
